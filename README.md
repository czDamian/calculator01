
# Calculator

A simple calculator application built using HTML, CSS, and JavaScript.

## About
This project showcases a basic calculator application that performs standard arithmetic operations. It was designed with a clean and responsive interface to ensure usability across different devices.

## Features
- Addition, subtraction, multiplication, and division operations
- Responsive design for mobile and desktop users
- Clear and user-friendly interface

## Installation
1. Clone the repository
   ```bash
   git clone https://github.com/czDamian/calculator01.git
   ```
2. Navigate to the project directory
   ```bash
   cd calculator01
   ```
3. Open `index.html` in your browser to use the calculator

## Usage
1. Use the on-screen buttons to input numbers and operations.
2. Press the "=" button to get the result.
3. Use the "C" button to clear the current input.

## Technologies Used
- HTML
- CSS
- JavaScript
